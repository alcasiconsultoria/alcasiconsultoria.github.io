Política de Privacidade (Privacy Policy)

Última atualização: 16 de Outubro de 2026

A privacidade e a segurança das suas informações são prioridades fundamentais para o Horizonte IA Studio. Esta Política de Privacidade descreve como os dados são coletados, processados e mantidos em nossa estação de trabalho local.

🔒 Armazenamento 100% Local: O Horizonte IA Studio opera como uma aplicação local (desktop/servidor local). Suas chaves de API, credenciais e vídeos são mantidos exclusivamente no seu próprio dispositivo e nunca são enviados a servidores externos de terceiros que não sejam as APIs oficiais expressamente autorizadas por você.

1. Dados Coletados e Finalidade

O Aplicativo apenas processa os seguintes dados para viabilizar as funcionalidades operacionais:

  • Tokens de Acesso OAuth 2.0 (TikTok e YouTube): Utilizados exclusivamente para autenticar requisições oficiais de envio e agendamento de vídeos nas suas contas autorizadas.
  • Chaves de API de Motores de IA (Google Gemini e OpenAI): Utilizadas para geração de roteiros, metadados de SEO e legendas para os documentários.
  • Metadados de Vídeo: Títulos, descrições, tags, miniaturas e legendas geradas para as edições do canal.

2. Não Compartilhamento e Não Venda de Dados

Nenhum dado pessoal, token de acesso, credencial ou arquivo de vídeo é comercializado, compartilhado, alugado ou transferido para terceiros, empresas de publicidade ou corretores de dados.

3. Conformidade com a Política da TikTok API

O uso das informações recebidas por meio da TikTok Content Posting API v2 adere estritamente às Diretrizes de Uso de Dados do TikTok:

  • O aplicativo solicita apenas os escopos indispensáveis para o envio de vídeos (video.upload, video.publish e user.info.basic).
  • Os tokens do TikTok são armazenados de forma criptografada ou restrita ao ambiente local do criador.

4. Conformidade com a Política da Google API

O uso pelo Horizonte IA Studio de informações recebidas das APIs do Google está em conformidade com a Google API Services User Data Policy, incluindo os requisitos de Uso Limitado (Limited Use requirements).

5. Retenção e Exclusão de Dados

Você tem controle total e absoluto sobre os seus dados:

  • As credenciais podem ser apagadas a qualquer momento diretamente no arquivo .env ou pelo painel Chaves de APIs.
  • Ao clicar no botão de Exclusão Permanente de uma edição no painel de Histórico, todos os arquivos físicos, metadados e comprovantes relacionados àquela edição são deletados permanentemente do disco.

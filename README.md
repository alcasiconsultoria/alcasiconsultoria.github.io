# Site Institucional - Horizonte IA Studio

Este diretório contém as páginas oficiais exigidas pelo **TikTok for Developers** e **Google Cloud Console** para verificação de domínio e aprovação de APIs de publicação de vídeo:

- `index.html`: Landing page oficial do canal e estúdio.
- `terms.html`: Termos de Serviço completos.
- `privacy.html`: Política de Privacidade em conformidade com LGPD, TikTok API e Google API.

## Publicação no GitHub Pages:
Para ativar em `https://alcasiconsultoria.github.io/`:
1. Crie o repositório público `alcasiconsultoria.github.io` ou `horizonte-ia-site` na sua conta do GitHub.
2. Faça o push destes arquivos.
3. Ative o GitHub Pages nas configurações do repositório.
